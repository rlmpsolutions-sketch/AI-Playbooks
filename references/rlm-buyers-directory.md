## Deal Matcher — Checklist

When matching an RV Park deal to buyers, confirm all of the following:

- [ ] Confirm pad count meets buyer minimum (25+ for Doron, 50+ for Adriana/Becky, 40+ for Tyler)
- [ ] Confirm cap rate meets buyer threshold (8%+ for Doron, 10%+ for Adriana)
- [ ] Confirm state is NOT excluded (Doron excludes IL, CA, NY)
- [ ] Confirm creative financing structure is in place (required by Doron)
- [ ] Confirm property type matches (transient / long-term / year-round)
- [ ] Gather T12 financials, rent roll, and aerial photos before submitting
- [ ] Submit to multiple buyers simultaneously — deals move fast
